Mode clair :

Police noire

* Bande en haut de l'application : 
	Gris foncé ✅ (#505050)
	Padding à voir
	Plusieurs onglets :
		* Fichier qui contient (pour l'instant) :
			Ouvrir
			Enregistrer
		* Crédit

* Liste des produits à gauche :
	Police Nunito
	Catégories -> 18px underlined
	Produits -> 14px
	Genre de menu hamburger pour afficher les produits de cette catégorie.

* Options cliquables en haut à gauche :
	Police Nunito, 18px underlined
	* Mettre un mur -> Gris clair (#C8C8C8)
	* Mettre une caisse -> Rouge (#FF4C4C)
	* Mettre une entrée -> Bleu (#81E8FF)

* Boutons en bas du plan :
	Ovales
	* Vider les éléments -> Vert (#4FFF4C)
	* Changer de plan -> Orange (#FFA100)
	* Supprimer le plan -> Rouge (#FF4C4C)

* Valeurs en haut à droite :
	Nunito 18px
	/!\ Emojis /!\
	Tous modifiables SAUF "Date de création" qui est déterminée automatiquement (Travail Noa)

* Infos cases en bas à droite :
	Affichage quand case du plan cliquée. 
	Numéro de case (ex : A16 ou K02)
	Liste produits dans la case -> Bouton supprimer Rouge (comme supprimer le plan) 
	Bouton en haut à droite, permettant de vider complétement la case cliquée -> Rouge (comme supprimer le plan)
